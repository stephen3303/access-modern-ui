Run native-smoke.ps1 with Microsoft Access installed. It creates a fresh isolated test database and refuses to overwrite an existing test file. It fails if Access shows any dialog during the run (tools/AccessWatch.ps1 records it in result.txt and ends Access), and it runs with g_Silent set, so a kit error that would open an error message fails the run instead, even when every check passed. All 205 checks passed on 64-bit Microsoft Access on 13 October 2026, before the column chooser's 15 checks were merged (they passed on its branch, 216 in all). The fixture supplies a test-only MeasureText stand-in; production apps should use their existing GDI measurement hook. Checks cover optional pagination, preserved height and scope on opt-out, complete paged records, full export scope, reused form instances, centered rows, header geometry and justification, long-text allocation, narrow-table scrolling, counted captions, rounded PNG rendering, focus rings (including a field inside a subform), toggle switches (on, off, locked, onChange, focus ring), search match marks (GridMark, GridHighlight, a field named name), required fields (`RequiredMissing` outlines and lists empty inputs), detail saves (`SaveDetail` saves an unchanged panel and reports a refused one), the message dialog's default OK button, dialog placement (`CenteredStart`) and the toast (it opens with its message, escapes `&` and leaves the focus on the form; added after that run). It loads the code with line numbers (tools/VbaLineNumbers.ps1), as the app builds do, so it also proves the numbered kit compiles and that the error log records the failing line. Column chooser checks cover layouts on a fit table: order, hidden columns and their captions, kept sort fields and rejected layouts. Header filter checks (29; 265 checks in all passed with 27 of them at cbd2120) cover the funnels' placement and colors, distinct column values (sorted, blanks merged and last, narrowed by the other filters, the column's own kept values still listed when the table is empty), filters combined with the page's filter, sorting and the column chooser, quoted values, a page that sets `Filter` itself, and `GridFit` moving the funnels.
